## 🚀 Git 速查（照抄即可，不用理解原理）

在仓库文件夹里右键 → 「在终端中打开」（或 Git Bash Here），然后：

```bash
git add .
git commit -m "2026-11-15 学习打卡"
```

第一次用需要告诉 Git 你是谁（只需设置一次）：

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

## ☁️ 发布到 GitHub（只需做一次）

1. 打开 <https://github.com/new>，建一个**公开**仓库，名字填 `learning-journey`
2. 建好后不要勾选任何初始化选项（不要选 Add a README）
3. 在仓库页面会有一段 "push an existing repository" 的命令，复制下来，在终端里依次执行：

```bash
git remote add origin https://github.com你的用户名/learning-journey.git
git branch -M main
git push -u origin main
```

（第一次会弹出登录窗口，登录一次以后就不用再登了。）

以后每次学完，只需三步：`git add .` → `git commit -m "日期 学了什么"` → `git push`。
